# Преподавательская Оценка Студентов

Консольный модуль оценивания студентов, разработанный с применением принципов DDD, слоёной архитектуры Ports & Adapters и паттернов GoF.

## Архитектура и слои
Выбрана архитектура **Ports & Adapters (Hexagonal / Clean)**:
- **`Domain/` (Центр):** Содержит сущности, объекты-значения, фабрику, доменный сервис расчёта итога и интерфейсы портов (`IStudentRepository`, `ICriterionRepository`, `IEvaluationRepository`, `IReportExporter`). Не имеет ни одной внешней зависимости (не знает ни про консоль, ни про CSV).
- **`Application/`:** Содержит сценарии использования (Use Cases) внутри `PosFacade`. Зависит только от `Domain`.
- **`Infrastructure/`:** Реализует порты домена (`InMemoryRepositories`, `CsvReportExporter`). Зависит от `Domain`.
- **`Program.cs` (Composition Root):** Собирает граф зависимостей через `Microsoft.Extensions.DependencyInjection` и предоставляет консольный интерфейс.

**Направление зависимостей:** `Program.cs` / `Infrastructure` $\rightarrow$ `Application` $\rightarrow$ `Domain`.

## Доменная модель и инварианты
- **Ubiquitous Language:** Студент (`Student`), критерий (`Criterion`), оценка (`Evaluation`), балл (`Score`), вес (`Weight`).
- **Инварианты:**
  1. Балл (`Score`) не может быть меньше 0 и больше максимального балла критерия (`MaxScore`).
  2. Оценку можно поставить только по существующему в рубрикаторе критерию.
  3. Вес и максимальный балл всегда строго положительные.

## Примененные паттерны GoF
1. **Порождающий (Factory) — `EvaluationFactory`:** Создает оценки через единую точку входа с обязательной проверкой инвариантов.
2. **Структурный (Facade) — `PosFacade`:** Предоставляет консольному интерфейсу простой набор методов для работы с системой, скрывая сложную работу репозиториев.
3. **Поведенческий (Strategy) — `IGradeStrategy`:** Позволяет менять алгоритм расчёта итогового балла студента (например, взвешенная нормализованная шкала).

## Запуск

dotnet run

## Роль ИИ в разработке
ИИ использовался точечно как справочник по синтаксису `Microsoft.Extensions.DependencyInjection` и для генерации шаблона xUnit-тестов.
